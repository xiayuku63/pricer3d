# Pricer3D 新手教程

这份教程面向第一次使用 Pricer3D 的用户，目标是完成第一份可靠的 3D 打印报价。应用内首次登录时会自动显示新手引导；如果已经跳过，可以从右上角的用户菜单重新打开引导。

## 1. 启动并登录

启动服务后打开：

- **本地开发**：<http://127.0.0.1:5000>
- **Docker 开发容器**：<http://127.0.0.1:5001>
- **Docker 生产部署**：通过域名或服务器的 80/443 端口访问

注册并登录后，先打开右上角的用户菜单 → **用户中心**。

## 2. 完成基础配置

### 2.1 选择打印机

进入 **打印参数 → 机型配置**：

1. 选择实际使用的打印机型号。
2. 选择喷嘴直径（常见值为 0.4 mm）。
3. 如果需要使用多台打印机，可以分别保存配置，并在报价页切换默认打印机。

打印机和喷嘴会影响可用的切片参数、打印时间和耗材估算。请尽量使用与实际设备一致的配置。

### 2.2 配置材料和颜色

进入 **打印参数 → 材料设置**：

1. 选择材料品牌。
2. 选择或新增材料类型，例如 PLA、ABS、PETG、TPU 或树脂材料。
3. 核对材料密度和单价。
4. 配置可用颜色；同一种材料可以维护多个颜色。

对于带多个实体的 3MF 模型，预览和切片会使用材料颜色映射。若报价中的颜色与实际耗材不一致，请先在这里补充或修正颜色配置。

### 2.3 设置切片预设

进入 **打印参数 → 切片配置**，按实际工艺设置：

- 层高
- 外墙层数
- 顶部/底部实心层
- 填充密度
- 底边宽度

设置完成后保存为预设。后续可以在报价页的默认设置栏或结果表中选择、替换预设。

### 2.4 确认成本与时间

进入 **成本与时间**，核对会参与报价的成本项：

- 机台费（元/小时）
- 上机/调机费
- 最低起步价
- 材料损耗
- 支撑占比和支撑单价
- 后处理费
- 时间固定开销

如果团队需要统一定价，可以由管理员设置全局默认值；个人设置保存后只影响当前账号。

完成以上配置后，点击底部的 **保存设置**。

## 3. 生成第一份报价

回到 **在线报价** 页面：

1. 将模型拖拽到上传区，或点击上传文件。
2. 支持 `STL`、`STP`、`STEP`、`OBJ`、`3MF` 和 `ZIP`。
3. 上传多个模型时，系统会在同一个结果工作区中显示每个文件的状态、重量、打印时间和费用。
4. 确认打印机、喷嘴、切片预设、材料、颜色和数量。
5. 点击 **生成报价**。

系统会优先调用 PrusaSlicer 估算打印时间和耗材；如果当前环境没有可用的切片器，则使用几何和参数估算，并在结果中保留状态提示。

## 4. 调整朝向和批量结果

### 智能摆放

在结果表中启用 **智能摆放**，系统会根据模型几何形状评估更合适的放置方向，尽量降低支撑、提高稳定性并减少打印时间。

### 手动调整

打开模型预览后，可以：

- 使用 **Lay on Face / 放置到面** 选择一个平面贴合打印平台。
- 使用旋转控件手动调整方向。
- 查看模型尺寸和预览结果。
- 保存当前朝向后重新计算报价。

调整朝向后建议重新生成报价，因为方向变化可能影响支撑、时间、耗材和最终价格。

### ZIP 清单报价

如果项目包含模型文件和 BOM/清单，可以上传 ZIP：

1. 系统先解析压缩包中的模型和清单。
2. 在预览窗口中检查模型、颜色和清单的匹配关系。
3. 对缺少匹配项的文件确认是否使用默认参数。
4. 确认后执行批量切片和报价。

## 5. 导出和查看历史

报价完成后，可以从结果区域导出：

- CSV
- Excel
- PDF

右上角用户菜单 → **报价历史** 可以查看最近报价，支持按文件名/材料搜索和按成功、失败状态筛选。历史清理会同时移除对应的报价记录、上传模型和 G-code 文件，但不会删除打印机、材料或其他用户设置。

## 6. 常见问题

### 没有生成准确的打印时间

检查 PrusaSlicer 是否已安装并被系统检测到：

- Windows：运行 `deploy/start_windows.ps1`，脚本会检测或静默安装仓库中的 PrusaSlicer 安装包。
- Docker：镜像会自动安装 Linux AppImage，并使用提取运行模式执行。
- 其他环境：在 `.env` 中设置 `PRUSA_EXECUTABLE` 指向可执行文件。

### 修改设置后报价没有变化

确认已经点击 **保存设置**。如果结果表中已有报价，可使用重新计算功能让当前结果应用新的打印参数、材料或颜色。

### 3MF 颜色显示不正确

确认模型确实包含多个实体或颜色信息，并在用户中心的材料设置中维护了对应颜色。对于不带颜色信息的模型，系统会使用当前报价行的默认颜色。

### 上传失败或模型无法预览

确认文件扩展名受支持、文件没有损坏，并检查服务端日志。超大模型建议先单独上传测试；ZIP 文件则先确认内部路径和文件名没有特殊字符。

## 7. 推荐工作流

> 用户中心配置 → 保存设置 → 上传模型 → 检查预览和朝向 → 确认材料/数量 → 生成报价 → 导出报价单 → 在报价历史中追踪记录
